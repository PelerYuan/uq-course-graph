# Network graphs

![Full graph](../../assets/images/course_dependency_graph.png)

The full graph shows all selected-plan courses plus external prerequisite nodes. Fill colors represent study status. External nodes are smaller and lighter. Focus courses receive a red outline. Solid and dashed edges distinguish prerequisite and recommended-prerequisite relationships.

For a readable figure, select a focused subgraph rather than plotting a large plan without filtering. Save high-resolution images with `dpi = 300` and increase `width` and `height` for dense networks.
