# Reproducibility

Record the repository commit, program code, route type, academic year, retrieval date, completed courses, and current courses alongside every published figure.

Keep the generated CSV inputs with the figures. This makes it possible to tell whether a later result differs because UQ changed its source data or because the analysis code changed.

For an offline demonstration, use the files in `examples/` and run the parsing, graph, and visualization stages without `01_scrape.R`.
